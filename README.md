# Analisis-de-portafolio-y-backtest
Análisis y backtesting en Python de un portafolio con SPY, IEF, GLD y VNQ (2010–2025). Compara rebalanceo por calendario y bandas, costos y ejecución diferida. Incluye análisis por subperiodos y ventanas móviles, Sharpe y Sortino con tasa libre de riesgo histórica, pruebas automatizadas y resultados reproducibles.
